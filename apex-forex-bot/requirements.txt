# Pinned to the versions currently running in production, read from the live
# Render build log — so these are known to resolve and install on the
# deployment's Python, not guessed.
#
# Why exact pins and not ">=": Render runs `pip install -r requirements.txt`
# on every build, so a floor alone means any upstream release ships itself
# straight into a live trading bot with no review. Twice in one day a
# transitive upgrade broke this project's own tooling. Reproducible builds are
# the point — bump these deliberately, not by accident.
#
# Every entry below is imported at runtime; the list was checked against the
# actual import graph. The `groq` SDK used to be here and was never imported:
# the Groq calls go out over plain `requests`.
