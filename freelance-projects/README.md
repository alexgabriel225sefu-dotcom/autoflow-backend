# Freelance Projects

Separate workspace for client/freelance bot & automation projects (Discord, LaborX, Fiverr, etc.), kept isolated from the Apex Trading Suite production app in the rest of this repo.

Each project gets its own subfolder, e.g.:
- `freelance-projects/hyperliquid-bot/`
- `freelance-projects/polymarket-bot/`

Nothing in here is wired into `server.js` or deployed with the main app.
