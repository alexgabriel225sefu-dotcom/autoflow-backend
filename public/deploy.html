🛠️ Deploy in 4 Steps

1

Create a free Railway account

Go to railway.app and sign up with GitHub or Google. It's free — no credit card needed to start.

2

Click the Deploy button below

Railway will automatically clone the bot and set it up. You just need to fill in your API keys.

3

Fill in your Variables

Railway will ask you for these settings. Fill them in one by one:

VariableValue
LICENSE_KEYYour key from above ☝️Required
BYBIT_API_KEYFrom bybit.com → API ManagementRequired
BYBIT_API_SECRETFrom bybit.com → API ManagementRequired
GROQ_API_KEYFree from console.groq.comRequired
TELEGRAM_BOT_TOKENFrom @BotFather on TelegramOptional
TELEGRAM_CHAT_IDYour Telegram chat IDOptional
SYMBOLe.g. XRPUSDT or DOGEUSDTOptional
PAPER_TRADINGtrue for demo, false for liveOptional
⚠️ Important: For Bybit API keys, go to bybit.com → Account → API Management. Enable Read + Trade permissions. Do NOT enable withdrawal permissions.
4

Click Deploy — your bot is live! ✅

Railway will build and start your bot automatically. In about 2 minutes you'll see it running. Open your Railway URL to see the live dashboard.

💡 Tip: Start with PAPER_TRADING=true to test without real money. Switch to false when you're ready to go live.
