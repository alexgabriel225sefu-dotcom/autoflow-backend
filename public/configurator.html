Pasul 2
Deployează pe Railway
A — Urcă codul pe GitHub (gratis, o dată)
1.Du-te la github.com → cont nou dacă nu ai → confirmi email
2.Click butonul verde New (sau + din dreapta sus → New repository)
3.Numești repo-ul apex-trade-bot → dai click Create repository
4.Pe pagina repo-ului apăsat click pe "uploading an existing file"
5.Dezarhivezi ZIP-ul descărcat → selectezi toate fișierele din interior → le tragi în browser → Commit changes
B — Deployează pe Railway (gratis)
1.Du-te la railway.app → Sign up cu contul GitHub
2.Click New Project → Deploy from GitHub repo
3.Alegi repo-ul apex-trade-bot pe care l-ai creat
4.Railway creează proiectul → mergi la tab-ul Variables
5.Click Raw Editor → lipești variabilele de mai jos → Update
6.Railway redeploys automat → botul pornește → primești mesaj pe Telegram
