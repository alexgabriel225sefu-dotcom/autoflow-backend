Configurația ta — deploy în 3 pași
VARIABILE DE MEDIU — Railway Raw Editor
1.Deschide railway.com → New Project → Deploy from GitHub repo → selectează apex-trade-bot → Deploy Now
2.Tab Variables → Raw Editor → lipești tot ce ai copiat mai sus → Update
3.Railway face redeploy automat. Dacă ai pus Telegram, primești mesaj că botul a pornit. Dashboard-ul e pe URL-ul Railway cu ?token= (e inclus în config).
Pași suplimentari MetaTrader 5
4.Copiază mt5/ApexBridge.mq5 din codul sursă în MetaTrader: File → Open Data Folder → MQL5/Experts, apoi restart MT5
5.Tools → Options → Expert Advisors → bifează Allow WebRequest și adaugă URL-ul tău Railway
6.Trage EA-ul pe chart-ul perechii (M5), setează BotURL + Secret (același MT_BRIDGE_SECRET din config) și pornește Algo Trading
