Complete Setup Guide
Make.com
1
Download blueprint + deschide Make.com
Apasă ⬇ Download .json de sus. Mergi la make.com → Sign up (gratuit) sau Sign in.
2
Creează un scenariu nou
Click pe Scenarios în meniu stânga → butonul + Create a new scenario (dreapta sus).
3
Importă blueprint-ul
Pe ecranul gol al scenariului: stânga-jos găsești bara de instrumente → click pe ··· (trei puncte) → Import Blueprint → selectezi fișierul .json descărcat.
⚠️ Dacă nu găsești ···, click-dreapta pe canvas sau caută butonul cu trei liniuțe în bara de jos.
4
Configurează modulul Webhook
Click pe modulul Webhook (primul modul, cu iconița de fulger) → Add → dă-i un nume → Save.

Make.com generează automat URL-ul webhook — copiază-l, îl vei folosi la 360dialog.
💡 URL-ul arată ca: https://hook.eu1.make.com/xxxxx
5
Configurează modulul AI
Click pe modulul AI / OpenAI → Add la Connection → introdu API key OpenAI → Save.

Promptul sistemului este deja completat de AutoFlow — îl poți edita după nevoie.
🔑 API key OpenAI de la: platform.openai.com → API Keys
360dialog — WhatsApp
6
Creează cont 360dialog
Mergi la app.360dialog.com → Sign up → alege "Direct API Access for Developers".
7
Conectează numărul WhatsApp Business
Click Add Number → introdu numărul tău de WhatsApp Business (nu cel personal) → urmează pașii de verificare prin SMS.
📱 Ai nevoie de un număr dedicat pentru business — nu poate fi folosit simultan în aplicația WhatsApp normală.
8
Setează Webhook URL
În dashboard 360dialog → click pe numărul tău → tab Configuration → câmpul Webhook URL → lipești URL-ul copiat din Make.com (pasul 4).
💡 URL-ul webhook din Make.com (de la pasul 4): https://hook.eu1.make.com/...
9
Pornește scenariul — LIVE!
În Make.com, în colțul stânga-jos al scenariului, dai toggle-ul pe ON. Botul tău este activ!
🎉 Testează imediat: trimite un mesaj pe WhatsApp la numărul conectat și ar trebui să primești răspuns în câteva secunde.
