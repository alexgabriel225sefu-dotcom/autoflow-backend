How to use these blueprints
①
Get your API key
Go to make.com → click your avatar → Profile → API access → click Generate new token → copy it

Connect your account
Click Connect Make.com in the bottom-left of the sidebar → paste your API key → select your zone and team → click Connect Account

After creation in Make.com: Open the scenario → connect your apps (OpenAI, Gmail, Google Sheets etc.) → replace the placeholder values (API keys, spreadsheet IDs) → turn the scenario ON. Each blueprint has a notes section with exact setup steps.

WhatsApp Auto-Reply Bot
Automatically reply to every WhatsApp message in seconds using GPT-4. Works 24/7 with your custom system prompt.
Modules: Webhook → OpenAI (GPT-4) → 360dialog HTTP Request
After creating the scenario:
1. In Make.com open the scenario → click the Webhooks module → copy the webhook URL
2. In your 360dialog dashboard → Settings → set webhook URL to the one you copied
3. Click the OpenAI module → connect your OpenAI account → customize the system prompt with your client's business name
4. Click the HTTP module → replace YOUR_360DIALOG_API_KEY with your 360dialog key
5. Click the Google Sheets module → connect your Google account → select or create a spreadsheet
6. Click the ON/OFF toggle to activate the scenario

AI Proposal Generator
Auto-generate professional client proposals from a form submission. Sends a polished PDF-ready proposal email instantly.
Modules: Webhook → OpenAI (Proposal) → Gmail (Send Proposal)
After creating the scenario:
