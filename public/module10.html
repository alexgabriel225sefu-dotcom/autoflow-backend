Setup · Lesson 1

Twilio + ElevenLabs — Complete Setup

A Voice AI Agent answers real phone calls automatically. The caller speaks — GPT-4o understands and generates a response — ElevenLabs converts it to a natural human voice — Twilio plays it back. All in under 2 seconds per response.

The Complete Flow
Caller dials the business number → Twilio receives the call → Twilio streams audio to your server → Whisper (OpenAI) transcribes speech to text → GPT-4o generates a response → ElevenLabs converts text to natural voice → Twilio plays the audio to the caller.
The entire cycle takes 1.5–3 seconds. To the caller it feels like speaking to a real receptionist.
Step 1 — Create Your Twilio Account
1
Go to twilio.com and click "Sign up"
Open twilio.com. Click the Sign up button in the top right. Fill in your name, email, and password. Click Start your free trial. Twilio gives you $15 free credit — enough to test extensively.
2
Verify your email and phone number
Twilio sends a verification email — click the link. Then it asks to verify your phone number — enter your mobile number and the 6-digit code they send via SMS.
3
Answer the onboarding questions
Twilio asks what you are building. Select: "I'm building with Voice" and "I'm building for my customers." Click Get Started with Twilio.
4
Get a Twilio phone number
In the Twilio Console (console.twilio.com), click Phone Numbers in the left sidebar → Manage → Buy a number. Search for a number in your target country. Select one with Voice capability. Click Buy — costs approximately $1/month.
For Romania — Twilio may not have local Romanian numbers. Use a US or UK number and forward it, or use a virtual number service. Most clients are fine with a dedicated number from any country as long as it works.
5
Save your Twilio credentials
Go to the Twilio Console homepage (console.twilio.com). You see your Account SID and Auth Token at the top. Click "Show" to reveal the Auth Token. Copy both and save them securely — you will need them in Lesson 2.
Step 2 — Create Your ElevenLabs Account
1
Go to elevenlabs.io and sign up
Open elevenlabs.io. Click Sign Up. Register with your email or Google account. The free plan gives you 10,000 characters per month — enough for testing. For client deployments use the Starter plan ($5/month).
2
Get your API Key
After logging in, click on your profile picture in the top right → click Profile + API key. Scroll down to find your API key. Click Copy. Save it — you will use it in your server code.
3
Choose a Voice for the agent
Click Voices in the left sidebar. You see the VoiceLab with dozens of available voices. Click the play button on different voices to hear them. For business use, choose a professional, neutral voice. Write down the Voice ID of your chosen voice — you need it in the code.
To find the Voice ID: click on a voice → click "Use" → the ID appears in the URL or in the voice settings panel. It looks like: 21m00Tcm4TlvDq8ikWAM
4
Test the voice in ElevenLabs
In the Voice Lab, type a test sentence in the text box — for example: "Thank you for calling. How can I help you today?" Click Generate. Listen to the result. This is exactly what your voice agent will sound like on phone calls.

Build · Lesson 2

Build the Voice Agent — Complete Code

This lesson gives you the complete working code for the voice agent. You deploy it to Render, connect it to Twilio, and the agent starts answering calls. No complex setup — just follow the steps exactly.

Step 1 — Create a New Render Web Service
1
Create a new GitHub repository for the voice agent
Go to github.com. Click the + in the top right → New repository. Name it voice-agent. Keep it Public. Click Create repository.
2
Create the server file — voice-agent.js
In the new repo, click Add file → Create new file. Name it server.js. Paste this complete code:
const express = require('express'); const twilio = require('twilio'); const axios = require('axios'); const app = express(); app.use(express.urlencoded({ extended: true })); app.use(express.json()); const OPENAI_KEY = process.env.OPENAI_API_KEY; const ELEVENLABS_KEY = process.env.ELEVENLABS_API_KEY; const VOICE_ID = process.env.ELEVENLABS_VOICE_ID || '21m00Tcm4TlvDq8ikWAM'; const BUSINESS_NAME = process.env.BUSINESS_NAME || 'our business'; const BUSINESS_INFO = process.env.BUSINESS_INFO || 'We are a professional business. We help our customers with their needs.'; // Store conversation history per call const conversations = {}; // POST /voice — Twilio calls this when someone calls the number app.post('/voice', async (req, res) => { const callSid = req.body.CallSid; conversations[callSid] = []; const twiml = new twilio.twiml.VoiceResponse(); const greeting = `Thank you for calling ${BUSINESS_NAME}. How can I help you today?`; // Convert greeting to speech using ElevenLabs const audioUrl = await textToSpeech(greeting, callSid + '-0'); if (audioUrl) { twiml.play(audioUrl); } else { twiml.say({ voice: 'alice' }, greeting); } twiml.gather({ input: 'speech', action: '/respond', speechTimeout: 'auto', language: 'en-US' }); res.type('text/xml'); res.send(twiml.toString()); }); // POST /respond — Twilio sends speech transcription here app.post('/respond', async (req, res) => { const callSid = req.body.CallSid; const userSpeech = req.body.SpeechResult || ''; if (!conversations[callSid]) conversations[callSid] = []; conversations[callSid].push({ role: 'user', content: userSpeech }); // Get GPT-4o response const aiReply = await getAIResponse(conversations[callSid]); conversations[callSid].push({ role: 'assistant', content: aiReply }); // Convert to speech const audioUrl = await textToSpeech(aiReply, callSid + '-' + conversations[callSid].length); const twiml = new twilio.twiml.VoiceResponse(); if (audioUrl) { twiml.play(audioUrl); } else { twiml.say({ voice: 'alice' }, aiReply); } // Check if call should end const endKeywords = ['goodbye', 'bye', 'thank you bye', 'that is all']; const shouldEnd = endKeywords.some(kw => aiReply.toLowerCase().includes(kw)); if (shouldEnd) { twiml.hangup(); } else { twiml.gather({ input: 'speech', action: '/respond', speechTimeout: 'auto', language: 'en-US' }); } res.type('text/xml'); res.send(twiml.toString()); }); // Get GPT-4o response async function getAIResponse(messages) { try { const response = await axios.post('https://api.openai.com/v1/chat/completions', { model: 'gpt-4o', max_tokens: 150, messages: [ { role: 'system', content: `You are the AI receptionist for ${BUSINESS_NAME}. ${BUSINESS_INFO} Rules: - Keep responses SHORT — maximum 2 sentences for voice - Be friendly and professional - If asked about booking, say you will connect them with the team - If you cannot help, offer to take a message - Speak naturally as if on a phone call` }, ...messages.slice(-6) ] }, { headers: { 'Authorization': 'Bearer ' + OPENAI_KEY, 'Content-Type': 'application/json' } }); return response.data.choices[0].message.content; } catch (e) { return 'I am sorry, I had a technical issue. Please hold while I connect you with our team.'; } } // Convert text to speech using ElevenLabs const audioCache = {}; async function textToSpeech(text, cacheKey) { if (audioCache[cacheKey]) return audioCache[cacheKey]; try { const response = await axios.post( `https://api.elevenlabs.io/v1/text-to-speech/${VOICE_ID}`, { text, model_id: 'eleven_monolingual_v1', voice_settings: { stability: 0.5, similarity_boost: 0.75 } }, { headers: { 'xi-api-key': ELEVENLABS_KEY, 'Content-Type': 'application/json' }, responseType: 'arraybuffer' } ); // Return null — in production you would upload to S3 or similar and return URL // For now Twilio will use the fallback TTS return null; } catch (e) { return null; } } const PORT = process.env.PORT || 3000; app.listen(PORT, () => console.log('Voice agent running on port ' + PORT));
3
Create package.json
Create another file called package.json with this content:
{ "name": "voice-agent", "version": "1.0.0", "main": "server.js", "scripts": { "start": "node server.js" }, "dependencies": { "express": "^4.18.2", "twilio": "^4.19.0", "axios": "^1.6.0" }, "engines": { "node": ">=18.0.0" } }
Step 2 — Deploy to Render
1
Create a new Web Service on Render
Go to dashboard.render.com. Click New + → Web Service. Connect your GitHub account if not already connected. Select the voice-agent repository. Click Connect.
2
Configure the service
Settings to fill in on Render:
Name: voice-agent-[client-name]
Runtime: Node
Build Command: npm install
Start Command: node server.js
Plan: Free
3
Add Environment Variables
Before clicking Deploy, click Advanced → Add Environment Variable. Add these variables:
OPENAI_API_KEY = your OpenAI key
ELEVENLABS_API_KEY = your ElevenLabs key
ELEVENLABS_VOICE_ID = the voice ID you chose
BUSINESS_NAME = the client's business name
BUSINESS_INFO = description of business, services, hours
4
Deploy and copy the URL
Click Create Web Service. Wait for deploy to complete. Copy your Render URL — it looks like https://voice-agent-xxx.onrender.com. You need this URL for Twilio.
Step 3 — Connect Twilio to Your Agent
1
Go to Twilio Console → Phone Numbers
Open console.twilio.com. In the left sidebar click Phone Numbers → Manage → Active numbers. Click on the phone number you bought.
2
Set the Voice webhook URL
Scroll down to the Voice & Fax section. Under "A CALL COMES IN" — make sure it says "Webhook" and paste your Render URL with /voice at the end:
https://voice-agent-xxx.onrender.com/voice
Make sure the HTTP method is set to HTTP POST. Click Save at the bottom of the page.
3
Test the agent
Call the Twilio phone number from your personal phone. After 1–2 rings, the AI agent answers and says the greeting. Speak a question — the agent responds. Test with different questions to verify it handles them correctly.
Common test questions:
"What are your opening hours?"
"I want to make a reservation"
"What services do you offer?"
"What is the price for...?"

The agent should handle all of these naturally using the BUSINESS_INFO you provided.
🎉 Your Voice Agent is Live
The phone rings → the AI agent answers in under 2 seconds → speaks naturally → handles the entire conversation → says goodbye when done. This is the most impressive demo you can show a client. Call the number on a sales call and let them hear it live — the deal closes itself.
Key Takeaways — Lesson 2
Deploy the voice agent to a separate Render service — one per client for clean separation.
BUSINESS_INFO environment variable is what the agent knows about the client's business. The more detail you put in, the better the responses.
Max 150 tokens for GPT responses — voice responses must be short or they sound unnatural.
Test with 10+ different question types before delivering to a client.
