FAQ

Common questions.

Do I need coding experience?
+
No. You copy-paste your Bybit API keys into Railway's environment variables and click deploy. The setup guide walks you through every step with screenshots. If you can follow instructions, you can run this bot.
What exchange does it use?
+
Bybit. Bybit has a full paper trading mode built in so you can test with zero real money at risk. We strongly recommend starting with PAPER_TRADING=true until you're comfortable with the bot's behavior.
Can I lose money?
+
Yes. Always start with PAPER_TRADING=true. Crypto trading carries real financial risk. The bot automates a strategy, but no strategy wins 100% of the time. We sell technology, not a guarantee of profit. Never trade with money you cannot afford to lose.
What AI does it use?
+
The primary engine is Groq — which has a generous free tier, so signals cost you nothing extra. Claude (Anthropic) is used as a fallback for deeper analysis. Both are optional and fully configurable via environment variables.
Can I change the strategy?
+
Yes. Every setting — coin pair, strategy, risk percentage, stop-loss, take-profit ratio — is an environment variable. No code changes needed. Switch between Turtle, Livermore, and Soros strategies in seconds.
