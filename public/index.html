FAQ

Common questions.

Do I need coding experience?
+
No. You copy-paste your Bybit API keys into the config file and click deploy on Railway. That's it. The setup guide walks you through every single step with screenshots. If you can follow instructions, you can run this bot.
What exchange does it use?
+
The bot is built for Bybit. Bybit has a full testnet environment so you can practice paper trading with zero real money at risk before going live. We strongly recommend starting on testnet first.
Can I lose money?
+
Yes — always start with PAPER_TRADING=true to test first. Crypto trading carries real financial risk. The bot automates a strategy, but no strategy wins 100% of the time. We sell the technology, not a guarantee of profit. Never trade with money you can't afford to lose.
What AI does it use?
+
The primary AI engine is Groq — which has a generous free tier, so you can run signals at no extra cost. Claude (Anthropic) is used as a fallback for deeper market analysis. Both are optional and configurable via environment variables.
