FAQ

Common questions.

Do I need coding experience?
+
No. You copy-paste your Bybit API keys into Railway's environment variables and click deploy. The setup guide walks you through every step. If you can follow instructions, you can run this bot.
What exchange does it use?
+
Bybit. Bybit has full paper trading built in — test with zero real money at risk. We strongly recommend starting with PAPER_TRADING=true until you're comfortable.
Can I lose money?
+
Yes. Always start with PAPER_TRADING=true. Crypto trading carries real financial risk. The bot automates a strategy but no strategy wins 100% of the time. Never trade money you cannot afford to lose.
What AI does it use?
+
The primary engine is Groq — generous free tier, so signals cost you nothing extra. Claude (Anthropic) is used as a fallback for deeper analysis. Both are optional and configurable.
Can I change the strategy?
+
Yes. Every setting — coin pair, strategy, risk %, stop-loss, take-profit — is an env variable. Switch between Turtle, Livermore, and Soros in seconds without touching code.
