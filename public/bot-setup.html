Setup Steps
1
Create a GitHub account & get the bot
Free — takes 2 minutes
✅
1
Go to github.com/signup and create a free account (just email + password — no credit card).
2
Once logged in, click the button below to copy the bot to your account:
🍴 Copy Bot to My GitHub → ⬇ Skip GitHub — download ZIP instead
💡 "Forking" just copies the bot code to your own GitHub account. You'll own your copy — it's free and takes 10 seconds.
2
Create a Bybit account & get API keys
Free — identity verification required (1–24 hours)
✅
1
Go to bybit.com → click Sign Up → enter your email and create a password.
2
Complete identity verification — click your profile icon (top right) → Account & Security → Identity Verification → upload your ID. Usually approved in 30 min – 24 hours.
3
Once verified, go to your profile → API → Create New Key → choose System-generated.
4
Give it a name (e.g. apex-bot). Under Permissions enable: Read + Trade. Leave IP restriction blank for now.
5
Copy both the API Key and the Secret Key — the secret is shown only once. Save them somewhere safe (Notes app, etc.).
⚠ Never enable "Withdrawal" permission on the API key — the bot only needs Read + Trade. This keeps your funds safe even if the key is ever leaked.
3
Get a free Groq AI key
Free — takes 2 minutes, no credit card
✅
1
Go to console.groq.com → click Sign In → create a free account (Google login works).
2
In the left menu click API Keys → Create API Key → give it any name → click Submit.
3
Copy the key that appears (starts with gsk_...). You won't see it again after closing, so copy it now.
✅ Groq is completely free for the volume the bot uses — no billing needed.
4
Create a Railway account
Free $5 credit — bot costs ~$1–2/month
✅
1
Go to railway.app → click Start a New Project → sign up with GitHub (use the same GitHub you created in Step 1).
2
Railway will ask to connect your GitHub account — click Authorize Railway. This lets Railway deploy your bot from GitHub automatically.
3
Add a payment method (card) — you won't be charged until your $5 free credit runs out, which takes several months at bot usage levels.
5
Deploy the bot on Railway
2 minutes — Railway handles everything
✅
1
In Railway, click New Project → Deploy from GitHub repo.
2
Find and select apex-trade-bot (the repo you forked in Step 1) → click Deploy Now.
3
Railway starts deploying. You'll see a build log — it'll fail at first because variables are missing. That's normal — continue to Step 6.
6
Add your keys to Railway
This activates the bot — takes 3 minutes
✅
1
In Railway, click your project → click the apex-trade-bot service → go to the Variables tab.
2
Click New Variable for each row below. Copy the name exactly and paste in the value from Steps 1–3.
LICENSE_KEY Your key shown at the top of this page
EXCHANGE Which exchange to use
BYBIT_API_KEY Your API Key from Bybit (Step 2)
BYBIT_API_SECRET Your Secret Key from Bybit (Step 2)
GROQ_API_KEY Your key from Groq (Step 3) — starts with gsk_
PAPER_TRADING Start with this set to true — simulated trades, zero real money risk
PAPER_BALANCE Simulated starting balance in USDT
TELEGRAM_BOT_TOKEN Optional — get alerts on your phone
3
After adding all variables, Railway redeploys automatically. Wait ~1 minute then check the Logs tab — you should see ✅ License verified and Bot started.
🎉 Once you see "Bot started" in logs — you're live!
The bot is now running 24/7, scanning markets and trading automatically.
🔒 When you're happy with paper results, change PAPER_TRADING to false to trade with real money. Only do this when you're confident.
